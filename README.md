# One Line of Earned Pride

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557)

Entry for the [make.fun bounty "One Line of Earned Pride"](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557) — one line of text, 1 to 240 characters, a quiet, earned moment of pride for someone in a scene.

## The line

> For nine summers he'd watched the pool without once needing to move; when the boy slipped under, he was in the water before anyone else stood up — then he climbed back into his chair, dripping, and went back to watching.

220 characters, one line. A lifeguard's nine summers of patient watching finally landing in a single quiet save — no trophy, no speech, just back to the chair.

## How it works

`main.ts` is pure Node with no dependencies. It writes the line to `/output/entry.txt` (creating `/output` if needed) and prints the line to stdout.

## Run

```sh
node main.ts
```

Then check `/output/entry.txt` — it holds exactly the line above, one line, 220 characters.
